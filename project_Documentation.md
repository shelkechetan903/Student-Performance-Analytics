# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

**Student Name:** Chetan Shelke

## 2. Objective
The objective of this project is to analyze student marks and attendance using Python, NumPy and Pandas. It helps identify student performance, grades, pass/fail status and top performers.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- CSV file handling

## 4. Dataset Description
The dataset contains 50 sample student records.

The columns include:
- Student ID
- Name
- Department
- Python marks
- Maths marks
- AI marks
- Attendance percentage

## 5. Implementation
1. Loaded the dataset using Pandas.
2. Calculated total marks and average marks.
3. Created a function to assign grades.
4. Checked pass/fail status using subject marks.
5. Analyzed average, highest and lowest marks for each subject.
6. Identified the top 5 students.
7. Analyzed student attendance.
8. Saved the final results into student_report.csv.

## 6. Key Features
- Total and average marks calculation
- Grade assignment
- Pass/fail statistics
- Subject-wise analysis
- Top 5 students
- Attendance analysis
- CSV report generation

## 7. Output
The program displays the student performance report, class statistics, subject-wise performance, top 5 students and attendance analysis.

Screenshots of the program output can be added here.

## 8. Final Outcome
The project successfully demonstrates how Python, NumPy and Pandas can be used to process student data and generate useful performance statistics.
