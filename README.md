# Student Performance Analytics System

## Project Overview
A Python-based project that analyzes student marks and attendance using NumPy and Pandas.

## Objectives
- Calculate total and average marks.
- Assign grades based on average marks.
- Identify pass and fail students.
- Analyze subject-wise performance.
- Find the top 5 students.
- Analyze student attendance.
- Save the final report as a CSV file.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV

## Dataset
The dataset contains 50 student records with these columns:
- Student_ID
- Name
- Department
- Python
- Maths
- AI
- Attendance

## Main Features
1. Student marks analysis
2. Grade calculation
3. Pass/fail analysis
4. Subject-wise performance
5. Top 5 students
6. Attendance analysis
7. CSV report generation

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install numpy pandas
3. Keep main.py and students.csv in the same folder.
4. Run:
   python main.py

## Output
The program displays student results, class statistics,
subject-wise analysis, top performers and attendance analysis.
It also generates student_report.csv.
